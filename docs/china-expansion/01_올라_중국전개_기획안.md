## 1. 한 줄 전략

> **"중국 인허가 리스크는 크로스보더(CBEC)로 우회해 90일 안에 판매 데이터를 만들고, 그 데이터로 광동성 거점(메인비즈 광동성지회 + KOTRA 광저우/선전 + 주광저우총영사관)을 통해 현지 총판을 붙인다."**

이유:
1. 루미세라가 이미 NMPA를 취득했다면 일반무역도 가능하지만, 신제품(올라)이 별도 비안이 필요할 경우 3~6개월이 걸린다. CBEC(티몰글로벌·JD월드와이드·더우인 글로벌 등)는 비안 없이 판매 가능해 시간을 산다.
2. 2026-07-29 NMPA 규제 완화(해외 신제품 중국 최초 출시 확약서로 본국 판매증명 대체, 유사 처방 안전성 자료 공동 사용)로 루미세라 기존 자료를 올라 비안에 재활용할 여지가 생겼다.
3. 김명진 회장님의 광동성지회(선전·광저우·둥관·후이저우, 한국 10사·중국 15사)가 이제 막 출범해 "첫 성공 사례"를 원한다. 우리가 그 사례가 되면 협회 차원의 지원을 끌어낼 수 있다.

## 2. 타깃과 포지셔닝

### 2-1. 타깃 소비자
- 1차: 1·2선 도시 25~40세 여성, 샤오홍슈 사용자, 두피·모발·바디 홈케어("居家护理")에 지출하는 층
- 2차: 광둥·하이난 등 남방 고온다습 지역(두피 트러블 니즈 높음), 한국 방문 경험이 있는 재한중국인·유학생 커뮤니티
- B2B: 미용실·두피관리샵(养发馆) 체인, 기업 판촉·복지몰(진성온 본업과 연결)

### 2-2. 포지셔닝 문장(중문 카피 방향)
- 韩国女性发明家研发 · 1,095天研究 · 天然来源成分 (한국 여성 발명가 개발 · 1,095일 연구 · 자연유래 성분)
- "한국에서 상을 받은 브랜드"(2026 여성발명왕EXPO 금상)를 신뢰 앵커로 사용
- 가격대: 중고가(中高端). 중국 로컬 브랜드와 저가 경쟁하지 않고, 일본·유럽 살롱 브랜드 대비 20~30% 낮은 가격 [확인: 진성온 공급가]

## 4. 90일 실행 로드맵

### Phase 0 (D+0~14) 정렬
- [ ] 진성온과 협업 범위·수익 배분 합의(MOU): 도트링크 = 중국 마케팅·채널·수출 실무, 진성온 = 제품·인증·공급
- [ ] 자료 수령: 제품 스펙, 전성분(INCI), NMPA 비안번호(루미세라), 시험성적서, 공급가·MOQ, 브랜드 에셋, 중문 상표 출원 여부 [확인]
- [ ] **중문 상표 선출원** (35류·3류·5류) — 중국은 선출원주의, 이 단계 누락 시 총판이 상표를 선점하는 사고가 흔함
- [ ] 김명진 회장님 감사 인사 + 광동성지회(손종수 지회장) 소개 요청
- [ ] KOTRA 광저우·선전무역관에 "지사화사업/온라인 상담" 신청, 주광저우총영사관 경제·통상 담당 영사 면담 요청

### Phase 1 (D+15~45) 씨딩 + CBEC 준비
- [ ] 샤오홍슈 브랜드 계정 개설(전문호), 재한중국인 KOC 30명 체험단 1차(예산 약 200~300만원)
- [ ] 중문 상세페이지·성분 스토리·수상 이력 콘텐츠 제작
- [ ] CBEC 입점: 티몰글로벌 TP(대행사) 또는 JD월드와이드 자영 입점 결정, 보세창고 1차 소량 입고(300~500세트)
- [ ] 알리바바닷컴에 B2B 리스팅(총판 문의 접수용)

### Phase 2 (D+46~90) 판매 데이터 확보
- [ ] 더우인 라이브 1~2회(광저우 MCN, KOTRA 선전무역관 '샘스클럽 입점' 같은 유통 사업 공고 병행 확인)
- [ ] 판매·리뷰·재구매 데이터 리포트 → 총판 제안서(Deck) 작성
- [ ] 광동성지회 회원사 대상 설명회(온라인) 1회
- [ ] KOTRA 광저우 무역관 주관 소비재 전시·바이어 매칭 신청

### Phase 3 (D+91~180) 총판·일반무역
- [ ] NMPA 비안(올라 신규 SKU) 착수 — 루미세라 자료 공동 사용 검토
- [ ] 광동성 총판 1곳 + 화동(상하이) 총판 1곳 계약
- [ ] 하이난 首尔见 매장 입점, 하이난 면세·이도 채널 검토

## 7. 리스크와 대응

1. **제품 카테고리 불명확(올라)** → 통화 내용 확인 후 인허가 트랙 재확정. 전기온열 제품이면 CCC 인증·수입 검역이 필요해 CBEC 우회 폭이 좁음.
2. **상표 선점** → Phase 0에서 즉시 출원.
3. **한중 관계·플랫폼 정책 변동** → CBEC 포지티브 리스트·관세 변경 상시 모니터링(KOTRA 해외시장뉴스 구독).
4. **총판 의존** → 데이터 없이 총판 계약하지 않음. 최소 90일 CBEC 데이터 확보 후 협상.
5. **가격 붕괴(串货)** → 채널별 권장가 통일, 총판 계약에 지역·채널 제한 조항.
