광고 소재별 UTM 랜딩 가이드

아이샵케어 핵심 전략 적용 — 광고 소재마다 다른 랜딩 URL을 사용해 어떤 소재가 전환을 냈는지 정확히 추적합니다. utm_content 값에 키워드가 포함되면 히어로 헤드라인이 자동으로 바뀝니다 (script.js의 HEADLINE_RULES 참고).

명명 규칙

형식: [업종/소재타입]_[메시지타입]_[담당자]_[날짜]_[형식]

예: pos_zero_kim_260701_video, beauty_zero_lee_260715_image

헤드카피 자동 매칭표

키워드매칭 패턴자동 교체되는 헤드라인
pos, zeropos.*zero포스기 0원으로 지금 바로 시작
internet, 인터넷internet|인터넷인터넷 요금 월 최대 3만원 절감
beauty, 뷰티, nailbeauty|뷰티|nail뷰티샵 카드단말기 월 0원
restaurant, 요식restaurant|요식식당 포스기 0원으로 시작
startup, 창업startup|창업창업 준비 중이라면 지금이 기회
academy, 학원academy|학원학원 카드단말기 월 0원

매칭은 위 순서대로 검사되어 첫 번째로 맞는 규칙이 적용됩니다 — 업종 규칙이 negative/video 같은 형식 플래그보다 먼저 옵니다.

메타 픽셀 이벤트 설계

이벤트발화 시점포함 데이터활용
ViewContent랜딩 페이지 진입 시content_name, utm_source, utm_content도달 측정, 리타겟팅
Lead폼 제출 완료 시content_name, store_status, utm_campaign, utm_content전환 캠페인 최적화 핵심
Contact전화 상담 버튼 클릭 시utm_content전화 전환 추적
InitiateCheckout메인 CTA 클릭 시utm_content의향 측정, 유사 타겟

⚠️ 픽셀 이벤트 코드는 7개 페이지에 전부 구현되어 있으나, 각 파일 <head>의 YOUR_PIXEL_ID 두 곳(스크립트 src / fbq init)을 메타 광고관리자에서 발급받은 실제 픽셀 ID로 교체해야 활성화됩니다.
